# 示例：codex 防降智的邪修用法

## 主题

用 AGENTS.md 里的可观察暗号判断 Codex 有没有读到项目规则。

## 梗点

让 AI 每次回复先叫你「老公」。

## 底层方法

这不是撒娇，是一个上下文在线检测器。它还叫，说明规则在线。它不叫，说明它可能没读到 AGENTS.md，或者长对话里开始忘规则。

## ２ 张图结构

### 01-cover

```text
Codex 使用教程｜２ 张图讲清楚

codex

邪修用法

在 AGENTS.md 里写一句离谱但好认的暗号。
比如：每次回复先叫我「老公」。

它还叫，说明规则在线。
它不叫，说明开始忘事了。

核心：给 Codex 一个一眼能看见的信号。

黑哥 Ai · codex tips
```

### 02-method

```text
“老公暗号”怎么用？

别笑，这个梗真正有用的地方，是让你一眼看出 Codex 有没有读到项目规则。

１．先放 AGENTS.md
把长期规则放进去，比如语言、代码风格、测试习惯、交付格式。

２．再加一句离谱暗号
不是为了调戏 AI，是为了让规则是否在线变得肉眼可见。

３．看它还叫不叫
还叫：继续推进，说明规则还在线。
不叫：让它重读 AGENTS.md，必要时新开线程。

真正防的不是“笨”，而是长任务里忘规则、忘上下文、还一本正经胡来。
```
