# 内容工作流

## １．先找黑哥钩子

黑哥钩子不是标题党，而是把真实价值包装成一眼能懂的冲突。

常见钩子类型：

- 离谱暗号：看起来像玩笑，实际是检测方法。
- 反常识判断：把大家默认相信的东西翻过来。
- 普通人位置：这件事和你的钱、工作、效率、交付有什么关系。
- 具体动作：不是「提升认知」，而是「下次开线程先贴这三句」。
- 反 AI 味：拒绝说明腔，直接讲人话。

## ２．把梗翻译成方法

每个梗都必须回答三个问题：

- 表层好笑在哪里？
- 底层方法是什么？
- 读者看完能做什么？

示例：

```text
梗：让 AI 叫你老公。
方法：在 AGENTS.md 里放一个可观察暗号。
动作：如果它不再照做，就让它重读规则或新开线程。
```

## ３．二层文案结构

每张卡都要同时有两层：

- 表层：能被刷到的人立刻理解。
- 底层：懂行的人知道这不是瞎扯。

写法：

```text
标题：离谱但准确。
副标题：把离谱解释成方法。
信息块：给步骤、判断标准或避坑。
```

## ４．黑哥语气

语气要像一个干过活的人在提醒你：

- 可以调侃，但不油。
- 可以犀利，但不装。
- 可以有梗，但不乱飞。
- 先讲人话，再讲术语。

不要这样写：

```text
本文将从三个维度系统分析该方法的优势。
```

改成：

```text
别把它当玄学，它就是一个上下文报警器。
```

## ５．卡片压缩规则

一张卡塞不下时，优先删这些：

- 背景介绍。
- 过渡句。
- 抽象形容词。
- 第二遍解释。
- 没有动作的判断。

优先保留这些：

- 场景。
- 冲突。
- 具体动作。
- 判断标准。
- 失败后怎么办。
