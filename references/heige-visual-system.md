# 黑哥视觉系统

## 基础画布

默认尺寸：

```text
１２００ × １６００
```

安全区：

```text
外边距 ５４ 到 １０４ 像素。
正文最大宽度 ９９０ 像素。
右下角保留署名区。
```

## 视觉关键词

- 暖纸底。
- 深墨字。
- 荧光绿重点。
- 黑底梗图气泡。
- 轻边框。
- 低饱和辅助色。
- 大标题，短段落。

## 默认配色

```text
纸底：#f7f4ec
主字：#3f403c
弱字：#6d6a63
荧光绿：#a8f06d
深绿：#6fb73b
浅蓝：#9cc7df
浅橙：#efb48d
黑底：#2d2f2a
```

避免：

- 大面积蓝紫渐变。
- 玻璃拟态。
- 背景光球。
- 强动画。
- 过度装饰。

## 字体层级

封面标题：

```text
９６ 到 １３２ 像素，粗体，行高 １．１２ 到 １．２０。
```

封面副标题：

```text
４２ 到 ５６ 像素，粗体，行高 １．４ 到 １．５。
```

教程页标题：

```text
５６ 到 ７２ 像素，粗体。
```

正文：

```text
２６ 到 ３４ 像素，行高 １．３８ 到 １．５５。
```

代码块：

```text
２２ 到 ２８ 像素，深色背景，短行优先。
```

## 标志性组件

### 荧光笔

用于强调 １ 到 ４ 个字，不要整行涂满。

### 黑底气泡

用于放梗、反转、结论。它应该像一句截图金句，而不是普通说明。

### 绿色编号

用于教程步骤。编号要大，要像手贴标签。

### 签名

右下角统一写：

```text
黑哥 Ai
```

如果需要副签名：

```text
黑哥 Ai · codex tips
```

## 版式禁忌

- 不要把卡片做成 PPT。
- 不要每张都堆满图标。
- 不要把正文塞到边框外。
- 不要让长英文撑破容器。
- 不要让标题出现孤字。
- 不要用动画解释信息。
